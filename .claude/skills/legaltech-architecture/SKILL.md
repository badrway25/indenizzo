# LegalTech Architecture Skill

When working on this project, always check:

1. Is every legal value connected to a source?
2. Is the source approved?
3. Is the calculation explainable?
4. Is there a disclaimer?
5. Are assumptions shown?
6. Are missing documents shown?
7. Is GDPR consent handled?
8. Are sensitive fields protected?
9. Is the user invited to human legal review?
10. Is the UX sober and professional?

Required calculation output:
- min estimate;
- mid estimate;
- max estimate;
- breakdown;
- assumptions;
- warnings;
- missing documents;
- sources;
- confidence;
- disclaimer.

Never present a simulation as a guaranteed result.
