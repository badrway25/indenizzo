{% translate "How to prepare your documents" %}

{% blocktranslate %}Gather what you have — the accident report, the medical report, the insurer's offer, pay slips. Upload them and the platform recognises each one, links it to the official sources and tells you what is still useful. Your files are analysed in memory and never stored.{% endblocktranslate %}

{% translate "Common questions" %}

{% translate "Is the estimate binding?" %}

{% translate "No. It is indicative and does not constitute legal advice or a guarantee. The actual amount depends on documents, expert reports and the competent court." %}

{% translate "What does it cost to try?" %}

{% translate "Running a simulation and preparing a summary is free. A professional engagement begins only with a separate written agreement." %}

{% translate "What happens to my documents?" %}

{% translate "They are analysed in memory to build your result and are not stored. You decide what to share with the Studio." %}

{% translate "Why does my case show no amount?" %}

{% translate "Because there is no validated official table for it yet. The platform never invents a figure — it helps you prepare your documents instead." %}

{% translate "What does it take to show an amount?" %}

{% translate "Three things: an official table or rule from a public authority, a clear way to apply it to your case, and a verified example to check it against. When all three exist we show the amount — otherwise we prepare your documents." %}

{% blocktranslate %}This documentation is informative and does not constitute legal advice. A simulation is indicative; the actual valuation depends on documents, expert reports, applicable law and the competent jurisdiction.{% endblocktranslate %}
