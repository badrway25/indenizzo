The browser otherwise discovers the @font-face declarations only after parsing fonts.css, which serialises the font fetch behind the stylesheet download. Preload pushes the fetch to start in parallel with the CSS, shaving ~100-300 ms off FCP under mobile throttling. We preload only the weights used above the fold; the rest stay lazy. RTL pages deliberately do NOT preload Arabic fonts: on RTL home (the only RTL page with a background-image hero) the hero image is the LCP element, and competing for HTTP/1.1 connection slots against two extra font requests measurably delays LCP. Without the preload the Arabic page recovers its baseline LCP while still benefiting from the CSS compression below. The CSP `font-src 'self'` already allows these — no policy change. `crossorigin` is required by the spec for preloaded font resources even when same-origin. {% endcomment %} {% if not IS_RTL %} {% endif %} {% comment %} F-p2-perf-1: critical CSS inline ABOVE the external stylesheets.
