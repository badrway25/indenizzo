# Validation pack — Defective product liability

**Country · category:** IT (and EU framework) · product_liability
**Status:** `not_calculable`
**Public behaviour today:** documental check + responsibility framing (no amount).

## Official source(s)
- **Codice del Consumo (D.Lgs. 206/2005), artt. 114–127** — defective-product
  liability (transposing EU Directive 85/374/EEC).
- **Directive 85/374/EEC** (+ the 2024 revision 2024/2853) — EU framework.

## Official URL / access
- Normattiva: https://www.normattiva.it (Cod. Consumo)
- EUR-Lex: https://eur-lex.europa.eu (Dir. 85/374/EEC, Dir. 2024/2853)

## Table / formula present
- **No.** These instruments define **liability and burden of proof**, not a
  monetary quantum. There is **no official statutory formula** that converts a
  defective-product injury into an amount — damage is assessed case-by-case
  (typically via the civil personal-injury tables, which is a different head).

## Harvest probe (P50, 2026-06-30)
- No table to harvest: the binding instruments contain **no monetary scale**.
  Reaching Normattiva/EUR-Lex returns the legal text, not a computable barème.

## Canary example
_Not applicable — there is no official monetary table to anchor a canary to._

## Blockers before `ready_for_engine`
- A statutory monetary formula would have to **exist** in official law. It does
  not. Any number here would be invented → forbidden.
