# P1-SEC-1 — local fonts + CSP tightening

**Date**: 2026-05-10
**Iter**: `F-p1-sec-1-local-fonts`
**Branch**: `p1/local-fonts-csp-hardening`
**Tag baseline P0**: `p0-technical-closure-2026-05-10` (commit `e86fdd7`).

## What changed

The four web fonts the platform uses (Inter / Cormorant Garamond /
Amiri / Tajawal) are now vendored under `static/fonts/` and served
locally. The CSP `style-src` and `font-src` directives drop the
upstream allowances:

- before — `style-src 'self' 'nonce-…' https://fonts.googleapis.com`,
  `font-src 'self' data: https://fonts.gstatic.com`
- after — `style-src 'self' 'nonce-…'`,
  `font-src 'self'`

Verified live on `/disclaimer/`:

```
content-security-policy:
  script-src 'self' 'nonce-xhOJ12Pgxz8PcFeTekBxfQ==';
  style-src 'self' 'nonce-xhOJ12Pgxz8PcFeTekBxfQ==';
  form-action 'self';
  font-src 'self';
  img-src 'self' data: blob:;
  base-uri 'self';
  connect-src 'self';
  default-src 'self';
  frame-ancestors 'none';
  object-src 'none'
```

| Tajawal | 400, 500, 700 | arabic | Boutros International | github.com/google/fonts/ofl/tajawal | OFL 1.1 |

The `.woff2` binaries were downloaded by `scripts/download_local_fonts.py`
via the official Google Fonts CSS API
(`fonts.googleapis.com/css2?family=…`) which serves a manifest of
versioned files hosted on `fonts.gstatic.com`. Each block was
filtered to the unicode subsets the platform actually serves (the
script discards `cyrillic` / `greek` / `vietnamese` etc.). License
files were fetched from each family's canonical upstream and
sanity-checked for the OFL marker before being committed.

## Inventory (committed assets)

19 `.woff2` files under `static/fonts/<slug>/` plus 4 OFL license
files under `static/fonts/LICENSES/`. Total `.woff2` size:
**959.8 KB** — under the 1 MB ceiling agreed in the brief.

```
static/fonts/inter/inter-{400,500,600,700}-{latin,latin-ext}.woff2  (8 × ~47 / ~83 KB)
static/fonts/cormorant-garamond/cormorant-garamond-{500,600,700}-{latin,latin-ext}.woff2  (6 × ~33 / ~37 KB)
static/fonts/amiri/amiri-{400,700}-arabic.woff2  (2 × ~98–106 KB)
static/fonts/tajawal/tajawal-{400,500,700}-arabic.woff2  (3 × ~9 KB)
```

`latin-ext` is kept for the LTR families because the platform
handles cross-border cases — a Polish/Czech/Romanian name in the
contact form must not fall back to system fonts.

### Console + network audit (live in dev)

- Console errors: 1 — only an unrelated `favicon.ico 404` (pre-existing on dev,
  not introduced by this iter).
- No CSP violation.
- No request to `fonts.googleapis.com` or `fonts.gstatic.com`.

`/static/css/fonts.css` and `/static/fonts/{inter,cormorant-garamond}/...`.
Network filter on `/ar/`: only `tajawal` and `amiri` `.woff2` files.

## What this unblocks for the future

- The CSP can stay tight when the Studio adopts new third-party
  surfaces (analytics, embeds): the baseline is now `'self'`-only
  apart from the explicit `data: blob:` for `img-src`.
- The platform can ship in environments with no outbound DNS to
  Google CDNs (corporate networks, air-gapped staging) without a
  visible degradation.
