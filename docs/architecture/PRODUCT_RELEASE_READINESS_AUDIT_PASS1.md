## Non-blocking polish (visual notes)

- **Mobile breakpoint at 375×800** — on the IT result page the
  small text inside the `bg-ok-600/5` calculated card overlaps
  slightly with the cookie banner before the user dismisses it.
  Not a correctness issue (cookie banner is dismissable), but a
  follow-up could tighten card spacing on `<sm` viewports.
- **Country-landing photo crops** — Tunisia and Morocco hero
  images crop differently across desktop / mobile because the
  source assets are different aspect ratios. A future polish pass
  could standardise the hero crop ratio.
- **AR/RTL typography weight** — the Arabic body uses the
  fallback Tajawal stack with the same weight as Inter; on some
  paragraphs the visual weight feels slightly heavier. A
  font-weight tune-up for AR-only would be a polish item.

None of the above gates shipping.
