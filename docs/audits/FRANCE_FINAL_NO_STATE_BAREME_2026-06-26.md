# France — final outcome: no state computable barème

Date: 2026-06-26 · Section: Francia (#10) · Decision: **guided path definitivo,
no numeric engine, no euro estimate.**

## Official basis (liability — confirmed)

- **Loi n° 85-677 du 5 juillet 1985 (Loi Badinter)** — governs the **right** to
  compensation for traffic-accident victims (liability), **not the amount**.
- Code des assurances; Code de la sécurité sociale (recours des tiers payeurs).
- (Légifrance blocks automated fetch — HTTP 403 — but the framework is settled.)

## Why no numeric engine

There is **no single state barème** producing an automatic amount:

- the **Nomenclature Dintilhac** is a *classification of heads of damage*, not a
  tariff;
- the **Référentiel Mornet** and the **barème de capitalisation « Gazette du
  Palais »** are practitioner / indicative references, **not state law**.

Quantum is fixed by the judge in concreto; these référentiels are guidance only.
Treating them as a numeric engine would breach the "official source only" rule.

## Conclusion

- Public state: `official_guided_path_approved` (chip: Loi Badinter; Code des
  assurances). **No euro estimate.**
- No approval pack required (no binding state barème). Inquadramento Loi Badinter
  + percorso assistito remains the correct public state.
