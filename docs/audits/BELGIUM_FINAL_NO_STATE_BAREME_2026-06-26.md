# Belgium — final outcome: no state computable barème

Date: 2026-06-26 · Section: Belgio (#11) · Decision: **guided path definitivo,
no numeric engine, no euro estimate.**

## Official basis (liability — confirmed)

- **Loi du 21 novembre 1989** relative à l'assurance obligatoire de la
  responsabilité en matière de véhicules automoteurs (Moniteur belge / SPF
  Justice).
- Code civil — responsabilité extracontractuelle.

## Why no numeric engine

Belgian bodily-injury compensation is assessed **in concreto** (case-by-case).
The **« Tableau indicatif » des montants** is compiled jointly by magistrates'
and judges' associations (Union royale des juges de paix et de police, etc.) and
is **explicitly indicative and non-binding — it is NOT a state law or tariff**.
Using it as a numeric engine would breach the "official source only" rule and
would not reflect a binding state barème.

## Conclusion

- Public state: `official_guided_path_approved` (chip: Loi du 21/11/1989;
  Code civil). **No euro estimate.**
- No approval pack required: there is no official state barème to import. Should
  Belgium adopt a binding state tariff in future, revisit.
